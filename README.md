# THE SOLAR CO. static website

A five-page, responsive front-end concept based on the supplied THE SOLAR CO. logo and Solar Buyers Guide.

## Pages
- `index.html` — main solar landing page and quote form
- `about.html` — story, mission, approach and value proposition
- `services.html` — residential, commercial, battery, design, installation and support
- `testimonials.html` — supplied buyer-guide story plus clearly labelled illustrative concepts
- `faq.html` — buyer-guide-based solar questions and answers

## Structure
- Shared styles: `css/style.css`
- Shared interactions: `js/main.js`
- Photography: `assets/images/`
- Icons: `assets/icons/` (reserved for future supplied brand icon files)

## Preview
Open `index.html` from a static web server. Internal links use relative file paths and work without a build step.

## Form behaviour
The quote form performs client-side validation and displays a local success state. It does not transmit or email data. Connect it to an approved form service or backend before production use.

## Content notes
No phone number, email address, physical address, certification, warranty, project count, savings percentage, or company performance statistic has been invented. The named testimonial is adapted from the supplied buyer guide; additional story cards are explicitly labelled as illustrative concepts.
